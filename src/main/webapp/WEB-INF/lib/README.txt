===============================================
  MySQL JDBC 驱动说明
===============================================

请将 mysql-connector-java-5.1.5-bin.jar 文件放置在此目录下。

下载地址：
  https://repo1.maven.org/maven2/mysql/mysql-connector-java/5.1.5/mysql-connector-java-5.1.5-bin.jar

或者从 MySQL 官方归档下载：
  https://downloads.mysql.com/archives/c-j/

注意事项：
1. 本项目使用 mysql-connector-java-5.1.5 版本
2. 驱动类名为 com.mysql.jdbc.Driver
3. 请确保该 jar 文件位于 WEB-INF/lib/ 目录下，Tomcat 会自动加载
